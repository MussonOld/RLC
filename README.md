На компьютере в ChatGPT
В левом нижнем углу нажми на своё имя / аватар.
Выбери Настройки.
В настройках найди раздел Приложения (Apps).
В некоторых интерфейсах он может называться Плагины.
Открой Каталог приложений / Каталог плагинов.
В поиске введи GitHub.
Выбери GitHub.
Нажми Подключить / Connect или Установить / Install.
Откроется GitHub — авторизуй приложение ChatGPT.
GitHub предложит выбрать, к каким репозиториям дать доступ. Выбери наш репозиторий.

В ChatGPT открой Настройки.
Перейди в Приложения (Apps).

Найди подключённый аккаунт.

На странице GitHub выйди из текущего GitHub-аккаунта или выбери Use another account / Использовать другую учётную запись.
Войди именно в нужный GitHub-аккаунт.
